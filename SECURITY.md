# Seguridad

Sitio estático de templates Start Bootstrap. No procesa datos de usuarios ni almacena secretos.

## Dependencias de terceros

Los themes incluyen assets de [Start Bootstrap](https://startbootstrap.com/) y librerías JS/CSS de terceros. Mantener dependencias actualizadas si se modifican los templates.

## Reporte de vulnerabilidades

Para el índice de este repositorio, contactá al mantenedor via [GitHub Security Advisories](https://github.com/ghcetraro/ghcetraro.github.io/security/advisories/new).
